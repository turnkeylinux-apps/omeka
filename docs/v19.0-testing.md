# Omeka 19.0 testing

## Source decision

Debian 13 Trixie does not package Omeka Classic. The appliance installs Omeka
Classic 3.2.1 from the official GitHub release asset and verifies the SHA-256
digest published by GitHub for that asset. Omeka 3.2.1 is the current upstream
release and explicitly supports PHP 8.4. PHP, MariaDB, Apache and ImageMagick
come from signed Trixie repositories.

Omeka documents a supervised update path. Administrators back up the database,
replace the reviewed application files while preserving local data and
configuration, then complete any database migration offered at
`/admin/upgrade`.

## Acceptance command

```sh
/sandboxed-git/turnkey/tools/test-v19-appliance omeka \
    --source /home/agent/.local/worktrees/turnkey-apps/omeka/wish-omeka-v19-trixie
```

The command builds the Trixie root filesystem, boots its normal systemd and
firstboot path in Docker, and runs `tests/v19.sh`.

## README crosswalk

| README contract | Focused check | Required result |
| --- | --- | --- |
| Omeka publishes cultural collection content | Create a public item through Omeka's model API, then request its public page | The titled item is stored in MariaDB and displayed publicly |
| Firstboot sets the Omeka administrator credentials | Log in through Omeka's real administrator form and inspect the stored hash | The dashboard loads and Omeka's current password format is used |
| Omeka is served over TLS | Validate Apache and request administrator and public pages over HTTPS | Both application interfaces load over TLS |
| ImageMagick supports media derivatives | Inspect the installed Trixie package | The supported ImageMagick executable is available to Omeka |
| Adminer, Webmin and local mail support are available | Query MariaDB, inspect Webmin modules and HTTPS, and check Postfix's loopback listener | The database works, Webmin answers and local SMTP listens |
| Debian packages receive Trixie updates | Inspect installed packages and active APT suites | Required PHP and MariaDB packages are installed and no Bookworm source remains |
| Omeka has a supervised upstream update path | Query the official latest release and asset digest, then check the documented retained paths | The installed release and digest match the current supported archive |
| SSH, backup and other base services are inherited from Core | Reuse the passing Core 19 baseline | Core 19 acceptance remains the inherited evidence |

## Deferred issues

The focused acceptance publishes a real metadata item without uploading a
large media corpus or installing third-party plugins. External mail delivery,
plugin compatibility and derivative throughput depend on the administrator's
content and extension choices.
